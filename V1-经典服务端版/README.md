作者：孜然　QQ：2937978586　微信：ZR293797

## 部署

1. 把本目录全部文件上传到站点根目录或二级目录（如 `/link/`）；
2. 直接访问即可，无需数据库、无需安装；
3. 需要 PHP 7.0+，Apache 下 `.htaccess` 已配置好；Nginx 请自行加禁止访问 `links.txt`、`config.php` 的规则。

本地预览：

```bash
php -S 127.0.0.1:8000
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.php` | 首页：域名输入 + 介绍 |
| `data.php` | 批量提交页；加 `&fmt=json` 可输出 JSON 数据 |
| `config.php` | 站点名、作者、QQ、微信、二维码、每批条数、倒计时秒数 |
| `lib/common.php` | 域名校验、外链库读取、分页 |
| `lib/layout.php` | 顶栏 / 页脚 / 二维码卡片 |
| `assets/` | 样式与脚本 |
| `images/` | 两张二维码，同名覆盖即可替换 |
| `links.txt` | 外链库，一行一条，用 `***` 作域名占位符 |

## 可调参数（config.php）

```php
'page_size' => 12,   // 每批提交条数
'max_size'  => 30,   // 每批上限
'page_wait' => 12,   // 每批倒计时秒数
```

## 注意

- 只填域名，不要带 `http://`、路径或末尾 `/`；
- 保持标签页在前台，浏览器会限制后台定时器；
- 部分 `http://` 站点会被浏览器的混合内容策略拦截，属正常现象。
